# Decision 0001 — Universal Ministerial Participation

**Date:** 2026-07-28  
**Status:** `OWNER_CERTIFIED`

## Contradiction found

The earlier Assembly formulation said that the ministry registry would select only relevant ministers before dispatch. That rule conflicts with the Assembly's founding principle that no upstream organ may decide a minister's relevance before the minister receives the common inquiry, and it conflicts with the Strauss minister's declared Sanctum participation rule.

## Authorities consulted

1. **Assembly founding principles in Sanctum.** The current README states universal participation: every established minister receives the same dismantled situation, and relevance is a ministerial judgment rather than a routing judgment.
2. **Strauss minister manifest.** `izzy9118-blip/Strauss`, `manifest.yaml`, version `1.20.0`, declares universal Sanctum participation and permits an `outside_my_ground` response.
3. **Sanctum README.** The historical selective-routing formulation and the current universal-participation language were compared as a forward constitutional correction rather than silently harmonized.

## Resolution

Universal participation governs dispatch. Every registered, established minister receives the same inquiry envelope. A minister may return a reasoned report or a null/outside-my-ground report. The latter is preserved as a complete ministerial response. The registry records Assembly membership; it does not rank relevance for an inquiry.

No minister-selection field may be used to suppress dispatch to an established minister. Any retained selection-shaped field in a compatibility schema exists only for schema stability and must represent the full registered minister set.
